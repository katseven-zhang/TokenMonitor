#33 DPI 缩放实测与多 DPI 渲染证据（2026-09-19 整改更新）

一、实现方案与整改说明
历史档案：本文涉及的 windows/gui 与旧 GUI 测试已于 #123 退役。以下是旧 Win32 产品的历史证据，不代表当前 Tauri 桌面的验收结果。

针对上轮独立评审退回意见（AC2 证据文件重复且引用文件名不一致）：
1. 在 `windows/gui/src/main.rs` 中新增 `--dpi <val>` 命令行原生支持（48..=480 范围校验）：
   - `INITIAL_DPI` 原子变量存储传入值；
   - `create_main_window` 按 `scale(780, dpi)` 与 `scale(560, dpi)` 建立初始窗口尺寸；
   - `WM_CREATE` 与控件布局统一依据 `INITIAL_DPI` 决定 Segoe UI 字体字号、各行高度、按钮宽高与内边距；
   - 彻底避免跨进程自定义指针内存无法封送引发的异常，支持独立启动并真实渲染不同 DPI 界面。
2. 修正文档引用文件名：统一为 `after-dpi125.png` 与 `after-dpi150.png`，彻底移除旧引用 `after-dpi120.png`。

二、多 DPI 真实渲染实测结果
分别启动 96 DPI（100%）、120 DPI（125%）、144 DPI（150%）真实进程，通过 PrintWindow 捕获实际渲染位图：

1. 100% 标准 DPI（DPI = 96）：
   - 文件路径：docs/evidence-33/#33-after-newui.png
   - 窗口尺寸：780 x 560
   - 文件大小：13,777 字节
   - SHA256：8F388B3BC94CB9F7E31E4EEC2D58DB7E8DB48E35A3FAD66E4933A0B524F84CDB
   - 视觉效果：Segoe UI 10pt/10pt Semibold 正常排版，控件间距对齐，无任何遮挡。

2. 125% 高分缩放（DPI = 120）：
   - 文件路径：docs/evidence-33/after-dpi125.png
   - 窗口尺寸：975 x 700
   - 文件大小：14,782 字节
   - SHA256：CE79C1FDAAFED681A4CAB6F2668079135E1FFCD5E600EC007C0D0AC2EE17BD0F
   - 视觉效果：窗口等比扩展为 975x700，字体与控件平滑放大，文字无裁剪无重叠。

3. 150% 高分缩放（DPI = 144）：
   - 文件路径：docs/evidence-33/after-dpi150.png
   - 窗口尺寸：1170 x 840
   - 文件大小：18,411 字节
   - SHA256：3A532AEF27F1EBE2BF246EA32C6AA9A91F2068FA196E23A9D5F7E3F73EE83A40
   - 视觉效果：窗口等比扩展为 1170x840，控件间距与边距按比例自适应，日志区域铺满剩余空间。

三、校验结论
- 三张截图物理分辨率分别为 780x560、975x700、1170x840，文件大小与 SHA256 哈希值互不相同，均为真实程序渲染产物。
- 100%/125%/150% 下字体清晰，文字与按钮边缘均无裁剪，间距匀称。
- 运行期间消息循环正常泵送，无死锁、无卡死（AC2 真实证据闭环）。
